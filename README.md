# Learn Windows Terminals 🖥️

> Uma documentação completa sobre terminais Windows (CMD e PowerShell)

## 📚 Sobre o Projeto

Learn Windows Terminals é uma documentação abrangente focada em fornecer um guia completo sobre os terminais do Windows. O projeto cobre desde conceitos básicos até técnicas avançadas de automação e integração com ferramentas modernas de desenvolvimento.

## 🎯 Objetivos

- Fornecer documentação clara e objetiva sobre CMD e PowerShell
- Apresentar exemplos práticos e exercícios
- Cobrir desde conceitos básicos até técnicas avançadas
- Manter material atualizado e relevante
- Facilitar o aprendizado através de uma estrutura progressiva

## 📋 Conteúdo

### CMD
- Introdução e conceitos básicos
- Comandos essenciais
- Operações com arquivos
- Scripting batch
- Automação e integração
- Networking e segurança

### PowerShell
- Fundamentos e sintaxe
- Cmdlets e pipeline
- Scripting avançado
- Módulos e extensões
- Integração com cloud
- DevOps e automação

## 🛠️ Tecnologias Utilizadas

- JetBrains Writerside (documentação)
- Markdown
- XML
- Batch Script
- PowerShell Script
