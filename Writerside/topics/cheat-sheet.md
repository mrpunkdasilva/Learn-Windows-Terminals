# Terminal Cheat Sheet

> "Seu guia rápido para comandos essenciais."

## CMD Essencial

### Navegação
```batch
cd [path]     # Muda diretório
dir           # Lista arquivos
cd ..         # Volta diretório
cd \          # Raiz do drive
```

### Arquivos
```batch
copy         # Copia
move         # Move
del          # Deleta
ren          # Renomeia
```

### Sistema
```batch
tasklist    # Lista processos
taskkill    # Mata processo
systeminfo  # Info sistema
ipconfig    # Config rede
```
