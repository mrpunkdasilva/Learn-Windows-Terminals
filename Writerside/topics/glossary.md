# Glossário

> "Entender os termos é o primeiro passo para dominar a tecnologia."

## A

### Alias
Comando alternativo/atalho para outro comando.

### Ambiente (Environment)
Conjunto de variáveis e configurações do sistema.

### API
Interface de Programação de Aplicações.

## B

### Batch
Script ou arquivo de comandos (.bat/.cmd).

### Binary
Arquivo executável ou programa compilado.

## C

### CLI
Interface de Linha de Comando.

### Cmdlet
Comando nativo do PowerShell.

## D

### Directory
Pasta ou diretório no sistema de arquivos.

### Domain
Domínio de rede Windows.

## E

### Environment Variable
Variável de ambiente do sistema.

### Execution Policy
Política de execução de scripts.

## F

### File System
Sistema de arquivos.

### Function
Bloco de código reutilizável.

## G

### GUI
Interface Gráfica do Usuário.

### GUID
Identificador Único Global.

## H

### Hash
Valor único gerado de dados.

### Host
Sistema ou computador na rede.

## I

### IDE
Ambiente de Desenvolvimento Integrado.

### Instance
Instância de programa ou serviço.

## J

### Job
Tarefa em background.

### JSON
JavaScript Object Notation.

## K

### Kernel
Núcleo do sistema operacional.

### Key
Chave (registro, criptografia).

## L

### Library
Biblioteca de código.

### Log
Registro de eventos.

## M

### Module
Módulo PowerShell.

### MSI
Instalador Windows.

## N

### Namespace
Espaço de nomes.

### NuGet
Gerenciador de pacotes .NET.

## O

### Object
Objeto (PowerShell/programação).

### Output
Saída de comando.

## P

### Parameter
Parâmetro de comando.

### Pipeline
Encadeamento de comandos.

## Q

### Query
Consulta (SQL, WMI).

### Queue
Fila de processos.

## R

### Registry
Registro do Windows.

### Remote
Acesso/operação remota.

## S

### Script
Arquivo com comandos.

### Shell
Interface de comando.

## T

### Task
Tarefa agendada.

### Thread
Linha de execução.

## U

### UNC
Convenção de Nomenclatura Universal.

### URI
Identificador de Recurso Universal.

## V

### Variable
Variável (ambiente/script).

### VBScript
Visual Basic Script.

## W

### WMI
Windows Management Instrumentation.

### Workflow
Fluxo de trabalho automatizado.

## X

### XML
eXtensible Markup Language.

### XPath
XML Path Language.

## Y

### YAML
YAML Ain't Markup Language.

## Z

### ZIP
Arquivo compactado.

### Zone
Zona de segurança.

---
_"Conhecimento começa com vocabulário."_
