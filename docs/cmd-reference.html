Exemplos Práticos

Backup

:: Backup com data for /f "tokens=1-3 delims=/ " %%a in ('%date%') do ( set BACKUP=backup_%%c%%a%%b ) xcopy /s /i "source" "%BACKUP%"

Limpeza

:: Limpa temporários del /s /q %temp%\*.* for /d %%x in (%temp%\*) do rd /s /q "%%x"
