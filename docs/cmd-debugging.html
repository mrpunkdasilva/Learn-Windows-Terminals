A Arte da Depuração (Ou: Como Perder Sua Sanidade com Estilo)

Debug Mode: Seu Novo Melhor Amigo

:: Ative o modo debug e observe o caos @echo on set DEBUG=true :: Agora você pode ver tudo queimando em tempo real

Técnicas de Debugging Para Masoquistas Digitais

1. Echo Debug (Para os Tradicionalistas)

@echo off echo [DEBUG] Iniciando script... echo [DEBUG] Variável X = %X% echo [DEBUG] Se você está lendo isso, algo deu errado

2. Logging Avançado (Porque Você Vai Precisar de Provas)

:: Crie um arquivo de log que ninguém vai ler set "LOG_FILE=%TEMP%\debug_%DATE:~-4%%DATE:~3,2%%DATE:~0,2%_%TIME:~0,2%%TIME:~3,2%.log" echo %DATE% %TIME% - Script iniciado >> %LOG_FILE% echo %DATE% %TIME% - Algo deu errado >> %LOG_FILE% echo %DATE% %TIME% - Como sempre >> %LOG_FILE%

Ferramentas do Debugger (Seu Kit de Sobrevivência Digital)

Error Levels: Seu Guia Para o Desespero

:: Verificando error levels call seu_script.bat if errorlevel 1 ( echo Houston, temos um problema goto :PANIC ) :PANIC echo Iniciando protocolo de pânico... echo Considere mudar de profissão

Pause Estratégico (Ou: A Arte de Congelar o Tempo)

:: Pausa dramática para debug set /p "DEBUG=Pressione ENTER para continuar o desastre..."

Técnicas Avançadas de Masoquismo

1. Step-by-Step Debugging

:: Debug passo a passo (para os muito pacientes) @echo on set "comando1=executando..." echo %comando1% pause set "comando2=ainda executando..." echo %comando2% pause :: Repita até perder a vontade de viver

2. Variável Watching (Stalking Digital)

:: Monitorando variáveis como um stalker set | findstr "IMPORTANTE" set | findstr "CRÍTICO" :: Observe suas variáveis desaparecerem misteriosamente

Armadilhas Comuns (Ou: Como Não Se Enforcar com o Próprio Código)

:: Armadilha #1: Espaços em paths if exist "C:\Program Files\Sua App" ( echo Parabéns, você caiu na armadilha mais básica ) :: Armadilha #2: Variáveis vazias if "%VAR%"=="" ( echo Surpresa! Sua variável evaporou )

Soluções de Emergência

  1. O Famoso Ctrl+C

    Quando tudo falhar, sempre existe o botão de pânico

  2. Taskkill

    :: Quando a sutileza não é uma opção taskkill /F /IM cmd.exe :: Adeus, cruel mundo dos processos

  3. O Reboot Mágico

    Porque às vezes, o melhor debug é um reboot
