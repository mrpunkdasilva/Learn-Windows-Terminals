"Bem-vindo ao PowerShell, onde tudo é um objeto e nada é apenas texto."

História e Evolução

Da Necessidade à Inovação

  • 2006: Lançamento inicial (PowerShell 1.0)

  • 2009: Windows PowerShell 2.0 (Remoting)

  • 2012: Integração profunda com Windows

  • 2016: PowerShell Core (Multiplataforma)

  • 2020: PowerShell 7 (Unificação)

Instalação e Configuração

Windows 10/11

# Verificar versão atual $PSVersionTable.PSVersion # Instalar última versão winget install Microsoft.PowerShell

Configuração Inicial

# Criar perfil pessoal if (!(Test-Path -Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force } # Configurar política de execução Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

Conceitos Fundamentais

1. Cmdlets

# Estrutura: Verbo-Substantivo Get-Process # Lista processos Stop-Service # Para serviço New-Item # Cria item # Descobrir comandos Get-Command -Verb Get Get-Command -Noun Process

2. Pipeline

# Encadeamento de comandos Get-Process | Where-Object { $_.CPU -gt 50 } | Sort-Object CPU -Descending | Select-Object Name, CPU, Memory

3. Objetos

# Tudo é objeto $processo = Get-Process chrome $processo.Kill() # Método $processo.Name # Propriedade # Explorar objeto $processo | Get-Member
